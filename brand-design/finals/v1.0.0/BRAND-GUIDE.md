# 智面幻境 / OfferPilot 标志规范

版本：v1.0.0 · 日期：2026-10-04 · 状态：正式封版，2026-10-04 用户确认。

## 标志定义

采用 01A 收窄主体与 A 字标搭配，英文为 OfferPilot、Segoe UI Bold 700。中文采用已选定 A 版字形轮廓。符号保留右高左低双肩、中央凹谷、双门和底部开放入口。语义顺序为“开门进入 → 面试舱 → m 联想”，表达开始模拟练习前的入口；不宣称观者无需解释便能理解全部含义。

交付 SVG 中字形均为轮廓路径，无字体安装依赖。不要通过重新输入文字来替代既定字标。source/ 中的文字工作稿仅用于维护。

## 文件选择

| 场景 | 文件 | 最小使用尺寸 |
|---|---|---|
| 独立标准符号 | svg/symbol-green.svg | 建议宽 32 px 及以上 |
| 小尺寸 / favicon | svg/micro-green.svg | 宽 16 至不足 32 px |
| 中文产品导航 | svg/lockup-cn-green.svg | 宽 180 px |
| 英文场景 / 教师导航 | svg/lockup-en-green.svg | 宽 185 px |
| 登录 / 品牌介绍双语 | svg/lockup-bilingual-green.svg | 宽 210 px |
| 深色背景 | 对应 -white.svg | 尺寸规则同上 |
| 黑白印刷 | 对应 -black.svg 或 -white.svg | 先按最终输出大小打样 |
| 应用图标设计源图 | svg/app-icon-square.svg | 按平台要求导出 |

独立符号不足 16 px 不使用。32 px 可以查看 micro 对照文件，但产品默认切换到 standard。组合最小宽度是本产品当前采用的规范值，不代表所有背景与印刷工艺下均已验证。印刷尺寸不从屏幕像素推导，需实际打样。应用图标为方形实底源图，不是完整 iOS/Android 图标安装包。

## 颜色

| 用途 | sRGB |
|---|---|
| 主绿色 | #10B981 |
| 字标主文字 | #172B22 |
| 双语英文副标 | #48564F |
| 单色黑 / 反白 | #000000 / #FFFFFF |

green 组合是绿色符号配深色文字；black/white 是整组单色。浅色干净背景使用 green 或 black，深色背景优先 white。避免复杂图像直接穿过侧缝，必要时放置单色背景面。当前未指定 CMYK、专色或实体印刷色样。

## 比例与安全区

独立符号保持原文件长宽比，不做非等比拉伸。原始几何宽 622、高 624 单位。以可见符号高度 H 为单位，标志外侧四周安全区至少 H/4；组合使用其中符号的可见高度 H。安全区从可见路径外缘起算，不从文件画板边缘起算，SVG 内部留白不能代替排版外围安全区。

完整组合应整体等比缩放，保留固定字距、图文间距和文字基线。维护工作稿中图文间距约 H × 0.33；生产排版直接使用轮廓 SVG，不重新拼接估算值。

micro 通过加宽门框侧缝到 40 单位改善小尺寸分离；standard 侧缝 25 单位。micro 不作为大尺寸轮廓替代，不应重新压缩侧缝。

## 禁止用法

- 非等比拉伸、旋转、镜像、改变门扇方向或左右双肩高低关系。
- 添加描边、渐变、阴影、发光、纹理或装饰图形。
- 改动已定字形、字距、颜色或 OfferPilot 的大小写。
- 把完整双语组合压入 favicon 或用标准版替代 16 px 补偿版。
- 分发 Windows 字体文件或把系统字体上传到网站作字体资源。

## 产品接入约定

共享组件 BrandLogo.vue 负责 cn/en/bilingual 与 inverse；LogoIcon.vue 根据 size < 32 自动切换 micro。桌面学生导航、移动导航和落地页为中文组合；教师导航为英文组合并附教师端身份文字；登录/注册/找回密码使用双语。favicon.svg 为 micro-green。

源资产目录为本版本 svg/。当前前端 src/assets/brand 中的文件为部署副本，不独立修改。更新须先生成新版本，再同步到产品，保持 manifest.json 校验一致。旧探索稿和旧版本包留作历史，不能与当前生产副本混用。

## 验证与发布边界

第六阶段：16 份纯路径 SVG、45 份 PNG；轮廓转换最大差异为 4 个 RGBA 通道值位置，没有字体或位图嵌入。第七阶段：Edge 浏览器中登录、注册、找回密码、落地页、桌面学生首页、教师首页和 360/390/430 px 移动首页检查通过；16/24/32/64 px 在 DPR 1/2/3 的浅底与深底测试容器中加载通过。

接口响应被测试脚本替换，仅证明显示和加载；不证明真实业务、原生标签页 UI、所有浏览器或实体印刷验收。真实受众识别与商标核验没有完成，不能宣称已获商标安全保证。当前本地产品已接入，用户已确认定稿，未发布。

发布前核对：用户最终视觉确认已完成；目标环境资源加载；标签页图标缓存刷新；目标浏览器截图；如涉及原生应用则补平台图标；对版本包校验值确认。任何新造型修改须升版本，不覆写本正式版本。

## 字体与来源

符号为本项目创作，基于用户提供的历史方案进行授权任务内精修。中文字形来源于 Windows 系统微软雅黑，英文来源于 Segoe UI Bold。字体仅渲染为既定 logo 文词的轮廓，不分发字体程序。微软允许 Windows 系统字体制作 logo 和图形，条件排除仅限家庭、学生或非商业的软件使用，字体分发与自托管另有限制。见 [Microsoft 字体 FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)，2026-10-04 已核对。

维护记录：本版本沿用第六阶段图形，未新改造型；第八阶段补充统一规范、校验清单与确认记录。
