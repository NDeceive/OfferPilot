# 发布准备与回退清单

状态：发布材料已准备；最终定稿确认和发布未执行。当前工作版本为 v1.0.0-rc1。

## 当前版本

01A 收窄主体，A 字标，英文 Bold 700。首页顶部采用绿色符号与白色中文字标，其他浅色场景沿用绿色符号与深色文字。17 SVG、45 PNG；新增 on-dark 变体为 SVG，未新增对应 PNG。

## 正式封版步骤

收到用户明确最终确认后，将本候选复制为独立 v1.0.0 目录，保留候选历史；更新确认记录、版本与 manifest，重新核对前端资源 SHA-256，生成正式包。不得仅改文件夹名便声称已经验收。

## 发布步骤

1. 在目标部署环境确认发布范围、入口和现有版本备份。
2. 构建前端，检查构建产物包含新标志和 micro favicon。
3. 预览目标构建，检查首页、登录、桌面和移动导航；首页顶部应为白色文字。
4. 按既有部署流程发布。发布操作须另有授权；本次没有发布。
5. 在目标地址验证 SVG 加载、无截断、favicon 缓存刷新；至少检查桌面与 360/390/430 px 移动布局。
6. 记录部署版本、目标地址、执行时间与验收结果。

## 回退

发布前保留目标环境当前前端构建及部署配置。出现资源加载或布局问题，恢复上一份完整构建，刷新对应缓存，再检查入口和 favicon。不要从探索目录挑选旧 logo 单独替换，否则可能造成组件和资产混用。当前仅有本地接入，未产生远端回退操作。

## 验证依据

evidence/ 保存第七阶段显示验收，新增 landing-white-wordmark.png 保存用户修订后的首页。接口测试响应不等于真实业务验收；暗色尺寸测试为独立容器。原生安装图标和全平台标签页外观不在已通过范围。
