# 智面幻境品牌资产 v1.0.0-rc1

第八阶段封版候选，待用户最终视觉确认。未发布。

先查看 delivery-board.png，再查看 evidence/ 的实际产品截图。使用规则见 BRAND-GUIDE.md，确认项见 CONFIRMATION.md。

- svg/：17 份纯路径标志，含首页绿色符号配白色文字的 on-dark 变体。
- png/：45 份透明或应用图标实底导出。
- source/：3 份文字可编辑 SVG 工作稿，可能依赖本机字体，不作为生产资源。
- evidence/：浏览器截图、场景记录与验收边界；页面数据为显示测试响应。
- audit.json：轮廓转换与路径审计。
- manifest.json：每个交付文件的 SHA-256 与 13 处产品资源一致性检查。

发布准备见 RELEASE-CHECKLIST.md。当前首页顶部采用白色字标；发布与最终确认尚未执行。

版本不混用：第六阶段包是历史交付候选；本包补齐第七阶段证据和第八阶段规范。任何造型修改另出版本。用户确认后再记录 v1.0.0 正式封版。
