## 使用

svg/：纯路径、无字体依赖的标准符号、小尺寸补偿符号及中文/英文/双语组合，均含绿色、黑色、白色。green 组合为绿色图形与深色文字；black/white 为整组单色。

png/：透明背景导出，白色版请置于深色背景查看。标准符号宽 32/64/128/256/512 px；补偿符号宽 16/24/32 px；组合宽 360/720 px；应用图标 192/512/1024 px 方形实底。source/ 保留文字可编辑工作稿，不是跨设备稳定的部署文件。没有字体文件随包分发。

## 规范草案

- 主绿色 #10B981；深色文字 #172B22；英文副标 #48564F；单色纯黑/纯白。深色背景优先使用 white。
- 独立符号高度为 H，四周安全区至少 H/4。组合以符号 H 为基准，外围安全区同为 H/4；源 SVG 画板不是安全区，排版时需另加。
- 16–24 px 优先使用 micro，32 px 及以上使用 symbol。不要把完整双语组合压入 favicon。
- 建议最小显示宽度：中文组合 180 px，英文 185 px，双语 210 px。这些为字号与比例推导的起始规范，尚待真实界面验证。
- 中文单行用于中文产品导航；英文单行用于英文材料；双语用于空间足够的介绍场景。
- 禁止非等比拉伸、旋转、改门扇方向、添加描边/阴影/渐变、压缩侧缝或把文字改成全大写。
- 应用图标保留方形实底，圆角由平台处理；不代表已完成 iOS/Android 全平台图标和掩模适配。

## 字体依据

中文微软雅雅黑的本机渲染字重、英文 Segoe UI Bold 700 已固化为 logo 单词/短语的图形轮廓；不是字体格式转换或字体文件再分发。Microsoft Windows 字体 FAQ 允许制作 logo 和图形，适用条件排除仅限家庭/学生/非商业用途的软件；字体文件自托管和分发另有约束。来源：https://learn.microsoft.com/en-us/typography/fonts/font-faq （2026-10-04 核对）。保留 source 中字体名称便于后续编辑。
