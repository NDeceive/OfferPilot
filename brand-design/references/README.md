# Reference library

Store links, notes, or locally permitted reference files by structural category:

- `liked/`
- `disliked/`
- `geometric/`
- `monogram/`
- `negative-space/`
- `wordmark/`
- `abstract/`

For every item, record source, creator/brand, observation date, license or usage basis, and the design principle being studied. References may inform proportion, grid, negative space, rhythm, stroke, or typography. They must never be traced, copied, or lightly modified into a new mark.
