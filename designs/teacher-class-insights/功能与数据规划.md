# 班级洞察：功能与数据规划

日期：2026-10-04。当前阶段只规划，不修改正式前端。定位：班级诊断与教学调整中心。

## 1. 代码核对结论

- `前端/src/views/teacher/ClassInsights.vue`：默认交由 TeachingPortal 展示真实班级管理；能力矩阵、散点等完整诊断主要位于 demo=1 演示流程。
- `前端/src/services/teachingApi.js` 与后端 TeachingController：已有班级、成员、任务（含分配）、教学报告及点评接口，不必从零创建业务系统。
- TeachingPortal 的 classes 分支加载成员及本班已发布任务，但不加载报告评分明细。首页/数据分析分支已有逐批读取报告及部分失败处理，可复用其模式。
- `teachingAnalysis.js` 已有真实报告版本识别、学生最近记录聚合和最小样本规则。不能直接复用演示服务中的固定目标80分、固定低频阈值及自主训练样本。
- 现有教学接口以教师授权任务为访问范围；成员关系不等于教师获得该学生所有自主训练报告的访问权限。
- 此核对依据代码，不代表已验证线上数据数量、质量及接口性能。

## 2. 功能清单与首版边界

| 功能 | 首版安排 | 唯一用途 |
| --- | --- | --- |
| 班级目录 | 卡片/列表、名称/学期搜索、归档筛选 | 定位要诊断的教学班 |
| 班级概览 | 关键证据、参与变化、关注名单入口 | 决定下一步教学重点 |
| 能力诊断 | 同口径能力柱状图、分段分布、能力矩阵 | 区分共性短板与个别差异 |
| 训练投入 | 教学有效训练频次、每周投入/参与组合图、按维度散点 | 找到未参与及高投入仍有短板的学生 |
| 教学跟进 | 多原因关注名单、创建针对性任务、任务前后配对评估 | 从诊断进入行动并回看变化 |
| 成员事务 | 独立入口保留成员、申请、邀请、编辑、归档 | 完整保留原有班级管理能力 |
| 自主训练来源对比 | 暂不进入首版 | 缺少已确认的授权数据入口 |
| 跨班级排名 | 不作为本板块主功能 | 综合对比由数据分析承接 |

## 3. 数据支持表

| 数据/指标 | 已有来源 | 支持程度与处理 |
| --- | --- | --- |
| 班级名称、学期、归档、成员规模 | classes、members | 可直接使用；成员名单以本班 JOINED 为准 |
| 任务生命周期、参与分配、减免、个人截止 | tasks(includeAssignments)、task | 可直接使用，完成率与能力分开展示 |
| 教学有效训练次数与参与人数 | assignment.attempts 的状态、valid、submittedAt | 可计算；READY 且 valid 不为 false，不能把生成中/失败计为有效训练 |
| 周参与率 | 同周期有效记录去重学生 / 当前已加入学生 | 可计算，标明当前成员口径；暂不宣称历史在籍率 |
| 成员加入前的历史参与率 | 当前成员接口不足以确认完整成员变更历史 | 暂不支持准确重建历史分母 |
| 能力原始分、目标分、维度、版本 | report.moduleScores、trainingContext.provenance、scorePlan | 条件支持；需要本班评分明细加载与版本分组 |
| 学生目标岗位 | 本次教学任务 jobId/jobName | 只表达任务训练岗位，不冒充学生个人求职目标 |
| 持续下降 | 同学生、岗位、维度及可比版本连续记录 | 条件支持；先核对增长规则，样本不足不下结论 |
| 待点评情况 | report reviews | 条件支持；获取点评状态后才能显示待点评人数 |
| 针对性任务预填 | create 页面 classId、studentIds、scoreModules | 表单支持指定学生，但尚未完整消费诊断页传入名单/维度 |
| 干预前后变化 | 同学生可比报告、目标任务开始/结束信息 | 条件支持；新增配对计算与时间选择，不宣称因果效果 |
| 自主训练次数、个人全部训练来源 | 当前教学报告接口未确认支持 | 不展示伪全量统计 |

## 4. 统计口径

1. 所有首版训练指标命名为“教学训练”；页面展示周期、岗位、有效样本、数据范围和更新时间。
2. 周期以 Asia/Shanghai 解释。训练按提交时间纳入，参与率按学生去重，次数按有效记录计数。
3. 任务完成率排除减免；统计单位为分配人次。同一学生参加不同任务分别计数。
4. 能力按选定岗位、维度和可比评分方案分组。每名学生先取该范围最近有效评分，再等权形成班级统计；不让多次训练者获得额外权重。
5. 首版沿用真实分析服务的至少5名可比学生才能显示班级能力汇总的规则。小于5人保留个人证据查看，班级图显示样本不足；显示被排除样本数量和原因。
6. 目标分来自实际评价方案，不写死80。不同目标、权重、规则/模型/提示版本按现有 versionKey 分组，并明确当前组；不暗中混合版本。
7. 分数区间围绕实际目标定义：达到目标、距目标不足10分、距目标至少10分；未评分独立列出。该10分为首版建议分组规则，应在口径面板中明示，并核对评分尺度后使用。
8. 不为训练频次设置未经确认的“优秀/落后”标签。频次先客观展示0次、1次、2–4次、5次及以上；未参与与未达到任务次数要求分开。
9. 多个关注原因合并到同一学生。无评分不等于低能力；数据读取失败不等于无记录。
10. 前后比较采用同一学生、同岗位、同维度、同可比版本。显示配对人数、未配对人数和时间边界；仅说明观察到的变化。

## 5. 页面结构与图表职责

### 班级入口

标题与创建班级/刷新 → 搜索、学期、使用中/归档、卡片/列表 → 班级目录。诊断信息加载前只展示已知班级信息，不预先生成“需要关注”标签。班级规模大时先列表及搜索，跨班评分不在入口全量加载。

### 班内页面

返回班级入口 → 班级标题、学期、成员管理 → 共用周期/岗位/口径 → 四个页签。

| 页签 | 主内容 | 图表存在的意义与操作 |
| --- | --- | --- |
| 班级概览 | 证据摘要 + 周训练柱/参与率线 + 能力差距柱 + 关注入口 | 周图判断覆盖是否扩大；能力图定位教学重点。点击周进入记录，点击维度进入能力诊断 |
| 能力诊断 | 可比方案选择 + 能力/目标柱 + 选中维度分段柱 + 学生能力矩阵 | 柱图找短板，分段图判断短板普遍性，矩阵支持分组。点击区间筛选名单，评分旁“查看依据”进入报告 |
| 训练投入 | 频次柱 + 次数/所选维度分数散点 + 学生名单 | 频次图定位覆盖；散点定位高频仍未达到该维度目标的人群。选中点或分组筛选名单，未评分人数单独说明 |
| 教学跟进 | 关注原因筛选 + 去重名单 + 关联任务选择 + 前后配对柱 | 关注名单承接诊断，配对柱观察任务后变化。默认先名单，选任务且数据可比后才显示配对图 |

散点横轴是周期内所选岗位的有效教学训练次数，纵轴是选定维度最近可比评分；不混用所有岗位次数与单岗位分数。重叠点提供名单查看和键盘替代入口。

不展示装饰性环形图、重复任务页的任务执行大图，以及无数据时的示意曲线。图表隐藏/空态不能导致核心名单与操作消失。

## 6. 联动约定

| 来源操作 | 目标 | 需要补齐的行为 |
| --- | --- | --- |
| 查看关注学生 | /teacher/students/:id | 携带 classId、jobId、周期、returnTo；目标页消费有效筛选并支持返回 |
| 查看训练证据 | /teacher/reports/:id | 权限检查沿用教学报告接口，保留完整来源 URL |
| 查看本班任务 | /teacher/tasks?classId=… | 不复制任务工作台；携带来源返回路径 |
| 对选中学生安排训练 | /teacher/tasks/create | 传 classId、studentIds、能力 code、returnTo；成员加载后校验并预选，失效成员给出提示；维度只作为建议，仍需教师配置完整评分方案 |
| 查看图表明细 | 班内名单/已有训练记录入口 | 周期、岗位、维度、区间保持一致，避免点击后回到全量名单 |
| 返回洞察 | 原始 returnTo | 保留页签、周期、岗位、方案、区间、搜索与列表展示；返回地址限定本地教师路由 |

每个参数以真实数据 ID 为准。既有演示链接的 students/ability 等参数不能认为已实现生产联动，需逐一适配。

## 7. 加载与状态

- 先加载班级/成员/任务，进入能力页签或需要能力摘要时再按本班范围加载报告；去重 reportId、限制并发并复用当前页面数据，避免每次筛选重复读取。
- 报告部分失败时显示覆盖不完整与重试，不把读取失败学生归为“未评分”。
- 保留初始加载、无班级、空班级、无训练、无评分、样本不足、无搜索结果、归档只读及权限失败状态。
- 手机端图表上下排列，矩阵优先姓名与选中维度，再展开其他维度；图表和表格筛选能通过文字控件完成。

## 8. 验收与下一步

验收路径：能力短板 → 查看区间名单 → 核对报告 → 指定学生创建草稿 → 发布任务 → 返回洞察选择任务 → 查看执行及可比前后变化。

核对跨班隔离、同学生去重、减免、个人截止、版本不可比、小样本、部分读取失败、跨模块返回及360/390/1440宽度。

下一步制作独立视觉评审稿，优先完成“班级入口、班内概览、能力诊断”的结构，再补投入与跟进视角。沿用浅灰底、白色内容区、翠绿主操作、少量边框花纹和透明彩色图标；数字不添加悬停下划线，选择状态用浅色背景/边框表达。评审稿数据明确标记为示例，不连接业务接口。
