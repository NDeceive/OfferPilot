# 数据分析指标契约 v1

2026-10-04 · 状态：用于下一轮独立评审稿及正式接入；现有正式统计尚未按本契约改造。

## 1. 统一分析范围

每次分析保存：教师权限范围、classIds、jobId、moduleCode、comparisonKey、from/to、snapshotAt、membershipBasis、metricVersion。班级ID先按教师权限取交集；无权选择的班级不作为空班处理，明确提示范围失效。

时间均为北京时间。界面起止日包含当天，程序使用[startOfFrom, startOfDayAfterTo)，读取截止不超过snapshotAt。近30天为今天及前29个自然日，不是任意720小时。周按北京时间周一分桶；首尾未满周标记不完整，不与完整周直接计算增幅。

人口分析默认“当前JOINED成员回看”，其分母固定为此次读取的当前成员集合。多班总人数按studentId去重，班内按(classId, studentId)。当前接口没有完整加入/退出事件序列，也未在people返回账号状态，故不称“历史在班人数”或“当前有效账号人数”。

任务执行分析默认“所选班级已发布分配”，保留历史已退出学生的授权分配；这不是当前成员人群。页面在执行图中另注明人数范围。两种范围不能暗中混用，点击图表带入同一口径。

岗位为教学训练岗位，不是学生求职意向。自主训练不纳入未经授权的教学统计。首次选岗位后才做能力比较，跨岗位训练量可以汇总，但不能汇总能力均分。

## 2. 事实数据字典与可用性

| 事实 | 唯一键 | 真实来源/字段 | 处理规则 |
|---|---|---|---|
| 班级 | classId | teaching.classes：id/name/semester/archived | 归档班级默认不选，可显式查看授权历史 |
| 当前成员关系 | classId+studentId | teaching.people：id/name/username/classId/className；members：studentId/state/accountStatus | people每行是关系，不能逐行算总人数；正常接收者必须到members复核 |
| 任务 | taskId | tasks/task：id/classId/jobId/publishedAt/startTime/deadline/endedAt/archived/minAttempts/scorePlan | 未发布草稿不进入教学分析；deadline为最新值 |
| 分配 | assignmentId | assignments：id/studentId/memberState/exempt/validCount/completionStatus/effectiveDeadline/effectiveMaxAttempts/overrideReason | 当前完成状态只能校验，不替代完成时间推导；个人截止优先 |
| 尝试 | attemptId；sessionId可交叉校验 | attempts：id/sessionId/state/valid/submittedAt/reportId/deadlineSnapshot | valid可能为布尔或0/1，严格归一；未知不计有效。尝试不因缺报告而丢失 |
| 报告 | reportId | teaching.report：report、问答与点评 | reportId去重读取；权限/网络失败保留readFailed原因，不静默丢弃 |
| 维度评分 | reportId+moduleCode | moduleScores：rawScore/targetScore/baseWeight/scoreSource | 有限数值才参与；0分是有效值；超出0–100或重复维度列数据异常，不自动修正 |
| 评分依据 | 比较键 | trainingContext.provenance及scorePlan | 完整比较键含岗位、维度、来源、目标、权重、完整方案及规则/模型/提示版本 |
| 调整历史 | 当前尚无已确认查询接口 | override仅当前值；数据库change log不等于前端可访问API | 不补造历史截止或减免状态 |

数据库存在尝试deadline_snapshot，但必须确认响应中deadlineSnapshot实际返回；它只能证明某次提交对应的截止，不能还原所有未提交分配在某日的截止。它也不解决历史成员、减免或评分完成时间问题。

原始响应 → 归一化事实 → 范围过滤 → 指标结果 → 图表/下钻/导出。中间结果保留recordIds/assignmentIds、分子、分母、排除原因；不能分别在图表和导出里重算另一套规则。

## 3. 状态分类

尝试状态ONGOING/GENERATING/FAILED/READY分别保留。有效训练定义READY且valid===true或1，并有合法submittedAt；无效READY单列，生成中不计有效也不视为失败。读取报告失败不改变已确认的有效训练次数。

学生证据概览每个学生只进入一种主状态，按优先级：读取失败 → 活跃生成中 → 活跃生成失败 → 未知/不匹配标准 → 有可比评分 → 无有效维度评分。为保证可解释性，另附“历史评分仍可查看”和全部次要状态；主状态是证据可用性，不是能力评价。读取失败影响其对应岗位/维度证据判断，不能据此说学生能力差。

能力比较以“最近有效READY报告中所选维度”确定当前证据；最近记录未知版本时不跳过它偷偷取更早记录，未知列为不足。生成中若仍有已完成可比报告，保留旧评分及日期，并注明新报告等待中。

## 4. 指标公式

| 指标 | 分子/统计对象 | 分母/条件 | 缺失与下钻 |
|---|---|---|---|
| 周有效次数 | 范围内按attemptId去重有效提交数 | 次，不除人数 | 点击列对应attemptIds；报告失败不扣已确认次数 |
| 周参与人数 | 周内至少一次有效训练的当前成员ID集合 | 人，与柱次数使用同一过滤范围 | 点击定位对应人员和尝试 |
| 参与率 | 周/周期参与人数 | 当前所选成员去重人数 | 分母0显示“无成员”，不显示0%；称当前成员回看参与率 |
| 频次分布 | 每个当前成员周期有效次数分入0、1、2–4、5+ | 各组人数合计等于当前成员人数 | 零次者在完整数据下仍显示；尝试数据加载不完整则暂停分布 |
| 人均有效次数 | 当前成员范围有效次数 | 同范围成员数，含零次 | 不是参与者人均；已退出人员记录不加入分子 |
| 到期执行结构 | 最新个人截止落在所选周期且已到期的非减免分配 | assignmentId去重；手动结束任务另列，归档历史须单独选择 | 四类：按期、逾期、未完成、完成时间未知；四类合计闭合 |
| 按期完成率 | 可确认完成时间且≤最新个人截止的分配数 | 按期+逾期+未完成；时间未知排除并显示数量 | 用“截至读取时刻、按当前截止计算”措辞，不宣称历史状态还原 |
| 能力均值/达标率 | 所选标准每学生最近维度分；达标为score≥target | 同批可比学生等权；至少5人，5–9提示 | 未匹配标准单列；不能自动取最大标准组当全体 |
| 目标差距 | 每人的target-score；分组≥20、10≤gap<20、0<gap<10、gap≤0 | 四组互斥；零分保留，未知目标排除 | 文字显示分界；不将不同目标标准直接合并 |
| 班级能力矩阵 | 每班所选标准的平均score-target | 同岗位、维度、标准；各班展示n，n<5留空 | 颜色为差距，空白表示不足，不用0代替 |

完成时间推导：将所有有效尝试按submittedAt升序，第minAttempts次的提交时间为达到次数要求时间（完成时间）；不足则未完成。若接口COMPLETED但无法推导，列时间未知，不能以当前时间填补。ONGOING/GENERATING不参与此序列。

该完成时间是按当前已生成报告复核出的有效提交时间，不证明在当日已被系统判定完成。历史“报告已生成比例”、原始到期按时率需要readyAt及调整历史，首版不展示。

各图保留截止版本说明，最新延期可能改变到期分组；首版明确“按当前要求重算”，不把变化自动解释为学生进步。

## 5. 具体任务的训练后比较

选择一项具体任务和维度，候选为截至分析截止已达到次数要求的非减免分配，人数按studentId去重。不能混合多项任务后每人任意选一项。

前记录：同学生同岗位、任务开始前最近有效维度报告，可早于筛选起始日。后记录：同学生同岗位、个人完成时刻之后且≤完成后14天的最近有效维度报告，不越过分析截止；不包含作为完成依据的那一条报告本身。

比较键必须完全相同，且匹配用户选定标准。优先选时间最近记录再核查标准，不跨过最新标准变更挑更旧记录。存在相关读取失败时该配对暂不判断。

观察截止不足完成后14天的候选标为“观察中”；已有配对可查看临时个人变化，但不进入完整观察窗口的聚合，以免与完整窗口混算。结束任务不等于每位学生已观察满14天。

候选主分类优先级：相关读取失败 → 观察中 → 无前记录 → 无后记录 → 评分/目标/版本不足或不同 → 不属于所选标准 → 有效配对。所有候选恰好归一类并合计闭合，次要原因另附。

聚合：有效配对至少5人才展示前均值、后均值和平均(after-before)。分布按原始差值<0、=0、>0，显示“分数降低/相同/升高”，不称持续成长。图中数值可以显示一位小数，但不按显示后的四舍五入值分类。记录数与可比版本不足时不判断持续下降。

## 6. 图表契约

每张图结果附范围摘要、snapshotAt、metricVersion、单位、分子/分母或n、排除数、完整性状态、对应明细ID和准确返回查询。

覆盖与节奏：次数柱+人数线，明确双轴；频次用100%堆叠柱，零成员无柱。班级比较：参与率条及任务分配结构，能力用差距矩阵。能力结构：差距人数分布及证据覆盖，重叠问题人群不绘饼图。训练后变化：同一配对样本前后分组柱和原始差值分布。

图表无样本显示恢复/核查入口，不生成装饰曲线。时间未满、观察未满、少样本、版本变更、报告部分失败都为可见状态。不同标准趋势不连线。已有演示算法、指标值和导出不能直接充当正式计算。

## 7. 手算验收样例

1. A班成员{1,2}，B班{2,3}：总体3人、每班2人，班级人数相加4不能当总体。
2. 学生1有效尝试两次、学生2一次、学生3零次：次数3、参与2、参与率2/3、成员人均1；频次组0次1人、1次1人、2–4次1人、5+0人。
3. 同一attempt同时出现列表与详情只计一次；READY valid=0不计，valid=1计，GENERATING valid=1不计。有效训练有reportId但报告读取失败，次数保留，能力不可确认。
4. 到期6条分配：减免1，其他为按期2、逾期1、未完成1、COMPLETED但时间缺失1。执行有效范围5，四类合计5，按期率2/4=50%，未知1明确排除。
5. minAttempts=2，有效提交10月1日、10月3日，无效10月2日：完成时间10月3日。个人截止10月4日则按期，即使任务默认截止10月2日；最新延期不代表原始历史按期。
6. 标准A有5名学生评分0/60/70/80/90，目标80：均值60、达标2/5=40%；差距四组2/1/0/2，合计5。另一个标准不能并入。只有4人时不显示均值与达标率。
7. 完成后第7天尚无后记录：观察中，不是“无后记录”；满14天后仍无后记录才归后记录缺失。
8. 完成候选8人：观察中1、读取失败1、无前1、有效配对5。配对差值-10/0/+5/+5/+10，均差+2，降低1/相同1/升高3，合计5；全部候选主分类合计8。
9. 10月1日00:00提交纳入10月1日范围；10月2日00:00排除；23:59:59.999仍属于10月1日。UTC时间必须转换北京时间分桶。
10. 班级对比中某班3名同标准学生：保留参与和执行数据，能力矩阵显示样本不足，不显示低能力或0分。

以上为契约手算样例，不代表已经运行生产统计。正式接入时将其写成归一化模型与计算函数的自动化验收。

## 8. 本阶段后续

进入独立视觉评审稿：先覆盖与节奏、班级对比；按上述契约展示可比人数、成员口径、当前截止、异常及下钻。再补能力结构、训练后变化。正式接入前补齐旧查询字段与新筛选的映射、准确日期、多班下钻、同结果导出，以及真实异常状态测试。
