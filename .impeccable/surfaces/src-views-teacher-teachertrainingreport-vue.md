# 教师端报告与全局联动

Mode: Operate。沿用教师端顶栏、白底、绿色操作、纯文字身份与清晰表格。成功路径是从训练明细/任务/学生下钻报告，核对来源和同口径评分，阅读存在的回答与证据，追加点评，再恢复来源范围。

报告不补造逐题正文、能力维度或证据，缺失内容逐节说明。点评必须明确本机演示，使用教师＋报告标识保存历史，并同步待办状态。390px明细表在自身容器内滚动，元信息折行，键盘焦点可见。

全局使用统一学生、任务、记录和报告 ID。导航传递规范化筛选，返回保留完整 URL；能力按最近当前版本样本计算。旧页面和重复数据适配器已移除，任务概览限制5项并附班级，降低重复展示和页面拉长。
