# 教师端演示数据

运行 `node scripts/seed-teacher-demo.cjs` 为本地开发数据库中的默认教师 `teacher` 填充演示数据。脚本通过真实教学 API 创建班级、申请、审核、任务、训练、报告与点评；不会删除或替换已有业务数据。演示班级与任务名称均以“演示 ·”开头，学生账号均以 `opdemo_s` 开头。

当前数据包含 3 个班级、18 名已加入学生、2 条待审核申请、7 个任务、20 份报告。其中 18 次为有效训练、2 次为提前结束的无效提交；双次训练任务同时包含完成、仅完成一次和未开始场景。另有 1 次训练中记录。任务覆盖草稿、进行中、待开始、已截止与已结束。

教师登录：`teacher`，本地默认密码 `123456`（脚本不会更改教师密码）。学生登录：`opdemo_s01` 至 `opdemo_s20`，初始演示密码 `DemoStudy2026!`。前 18 人为已审核成员，后 2 人为待审核申请。可通过环境变量 `TEACHER_DEMO_USER`、`TEACHER_DEMO_PASSWORD`、`STUDENT_DEMO_PASSWORD` 指定现有演示账号凭据。

入口：`http://localhost:5173/teacher/dashboard`。使用默认真实数据模式即可查看，无需添加 `?demo=1`；旧的前端预览模式不会显示这些数据库记录。

原始分数由当前报告服务生成，未手工改写成绩。历史演示时间分布在近两周，任务发布时间与提交时间保持先后关系。任务明细、有效次数、原始报告、学生任务入口、教师待点评和消息均关联同一组实体 ID。

重复运行会根据演示名称与账号复用记录，保留已产生的训练和点评，不重复创建同一组数据。若教师或学生已更改演示账号密码，应通过环境变量提供当前密码，不会自动重置账号。

清单保存在 `output/teacher-demo-data.json`，其中不包含 JWT 或密码。验证命令：`node scripts/check-teacher-demo.cjs`，检查真实接口、任务状态、报告权限、学生联动和桌面/移动端页面。
