# 学生中心正式接入 · 2026-10-04

正式 `/teacher/students` 与个人详情应用学生支持评审稿。原 `demo=1` 页面保留。

- 成员关系按学生合并，班级筛选后重新计算证据；只分析教师授权教学训练。
- 支持需求包含共同短板、执行受阻、未开始、逾期、已有投入仍有短板、接近/达到目标和证据待补齐。分群可重叠，不可相加。
- 教学岗位单独选择；能力维度及评分口径由实际报告产生，目标来自报告，不使用固定80分。规则使用最近有效维度评分；训练次数限定所选周期。
- 人群柱状图帮助选择需求，差距柱状图筛选短板，投入散点进入个人档案，个人柱状图链接原报告。同岗位、维度、版本才能比较；未知口径和读取失败不判能力。
- 个人档案链接报告与点评、原任务个人分配及补练/截止调整。报告生成中、报告失败与无效回答分别显示。
- 所选名单先核对目标班级，再进入已有训练草稿配置。创建页校验正常已加入成员并预填接收者；不会自动创建或发布。跨班只安排所选目标班级，剩余学生须另行核对。
- 支持需求无独立持久化接口，因此不提供“标记已解决”。当前也不判断连续下降或声称训练的因果效果。

验证：`node scripts/check-student-support.mjs`、`node scripts/check-student-support-browser.cjs`，浏览器使用隔离的模拟接口，不写入真实业务。覆盖跨班去重、证据隔离、数值型有效标记、任务排除、个人截止、生成与失败、未知版本、分页、档案、草稿范围以及1440/390/360宽度。正式前端 `npm run build`。

复用 OfferPilot 已确认按钮色、透明边框装饰及现有 TeacherDrawer；未新增依赖或后端接口。

## 筛选与布局修订

班级和训练岗位使用带搜索的选项面板，长名单可滚动，支持空结果、Esc关闭和焦点离开关闭。训练周期和观察维度保留标准选项框。评价标准折叠为中文说明与目标、可比人数，技术版本放在进一步展开项中。左侧全部学生置顶，去掉分群柱条；共同短板的两根柱改为紧凑的差距筛选按钮，右侧名单为主要内容。投入散点和个人可比评分柱保留实际定位、核查用途。浏览器检查加入36个岗位、37个班级的选择场景。
