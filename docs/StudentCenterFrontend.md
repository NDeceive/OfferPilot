# 教师端学生中心前端落地

2026-10-03。用户批准按照压缩包分析方案制作前端。包内提示词作为实施参考，页面规格与 FINAL_OVERRIDES 优先于生成预览图。

最新全局整合说明见 [TeacherFrontendIntegration.md](TeacherFrontendIntegration.md)。

## 范围与入口

- `/teacher/students`：T06，班级、姓名/学号搜索、排序、分页；更多筛选包含岗位、最近训练、成长变化与跟进条件。变化和跟进条件可同时生效，URL保存条件，收起筛选后可移除已生效标签。
- `/teacher/students/:id?tab=overview`：T07-01，纯文字身份、学习状态摘要、透明关注事实、四项水平条、最近训练与待完成任务。
- `?tab=ability&ability=project_expression`：T07-02，单项能力、7/30/90天/本学期、通用/岗位能力、目标与趋势、记录变化及C06证据。URL兼容能力中文名称。
- `?tab=training&history=records|tasks`：T07-03，两张表互斥展示。默认训练记录，支持时间、来源、形式、岗位、内容过滤及分页。
- C06：约800px右侧Drawer，当前值样本、口径、版本、记录和报告链接、原报告证据与关联任务。支持Esc关闭、键盘焦点管理与手机宽度。

未制作星标、教师记录、综合能力分、雷达图、排行榜、风险分和无来源AI建议。

## 数据与口径

适配层为 `前端/src/services/studentCenter.js`。保留 `student_center_mock_baseline.json` 原包Mock作追溯参考。原包只提供一名学生和能力快照，缺少对应报告与趋势记录，且日期晚于当前日期；未用这些孤立快照冒充可追溯能力值。演示复用已有班级和训练记录，基于任务模块的2026-10-03 15:00北京时间计算窗口。

T06名单来自已加入班级成员，停用账号可查看历史但不能成为新任务对象。总览、班级、任务和学生中心共用 `ci-*` 学生身份、统一任务及报告 ID；旧 `demo-student-*` 身份已停用，无法可靠映射的旧链接显示不存在。生产API未提供授权名单、学生详情、能力目标和证据，真实模式明确为空，不显示演示人物或评分。

近30天次数指已有有效训练记录。成长状态复用 teacherModel.growthFor：至少6条同岗位、同模型、同版本有效记录，最早3条与最近3条均值比较，±3分阈值；持续下降优先规则为最近3条严格下降且累计下降至少5分。单项能力使用相同算法，输入所选能力评分；不另建阈值。

当前能力取选定范围当前连续评分阶段的最近最多3次有效评分。1条显示最近一次评分，2条显示最近2次平均；成长数据不足不妨碍查看已有评分。岗位或模型/版本切换不桥接旧阶段；缺失与无效评分不补0。历史岗位只能从实际记录选择。演示通用能力目标80明确标注为演示配置；岗位能力未配置目标则不显示目标线或分差。生产目标不能回退成80。

任务状态与有效完成次数复用 trainingTasks.js 的 completionStatus / validAttemptCount；逾期是独立时间属性，历史逾期完成与当前逾期未完成分开。任务结果只使用其自身的有效报告；历史训练与任务包独立的演示评分不强行互相替换。

排序优先级：持续下降、当前逾期未完成、近30天0次有效训练、仅1次、其他。同等级按最近训练从早到晚，无记录优先，再按学号。没有确认的能力差距阈值不参与排序。主要关注与专项入口给出实际分差依据，不写因果结论。

C06表现原文只接受同时匹配 trainingRecordId / reportId / abilityId、正向或待改善类型的 evidence 数据。已有演示没有原报告文本，显示明确缺失说明，不生成回答与评价。报告不可访问时保留评分记录并标记不可用。

## 复用与跨模块

复用AppLayout、TeacherDrawer、已有成长算法、班级名单、报告详情入口和T10/T11。StudentAbilityChart使用原生SVG与ResizeObserver，固定0–100分纵轴，按真实时间间隔定位，手机上保持刻度可读，没有新增依赖。

班级能力入口携带所选能力及班级Tab；T11查看学生携带sourceTaskId。来源返回只接受已知教师内部路径。列表→详情返回恢复原筛选。C06→报告→学生保留能力Tab；学生→T10预填班级、学生和能力并记录STUDENT_ABILITY/OVERVIEW来源；T10退出和T11返回保留原学生页面。D02查看全部记录带实际既有student参数和来源返回。

共享TeacherDrawer显式把属性传至Teleport内的遮罩，修复调用方Drawer宽度/主题class丢失；学生视图保持单根AppLayout，兼容现有路由out-in过渡。报告仍复用既有入口，没有新建报告系统。

权限保持TEACHER/ADMIN路由校验。演示详情限定有效班级成员；真实student:view、student:view_ability、student:view_training、task:create、report:view能力与班级归属必须由后端接口返回并检查，当前未接入，不把前端演示检查当生产权限。

## 本轮简化（2026-10-03）

按用户确认的顺序，先修正状态与结果口径，再删除重复内容，最后简化筛选和操作入口。

- 列表与概览使用“训练报告表现变化”，能力页使用“单项评分变化”；数据不足说明实际样本数、岗位或评分口径切换等原因。报告相邻分差仅比较有效且同岗位、同模型版本的评分，首次记录和不可比记录显示原因。
- 最近训练日期和时间筛选均取有效评分记录。待完成任务包含自然逾期未完成任务，排除已完成及手动结束任务；逾期数量从同一集合计算。
- 删除页头重复人数、能力条重复分差与证据面板重复摘要。差距最大只作为可查看依据的事实，不自动推荐训练；计算口径和原始标识按需展开。
- 能力范围与能力合并为分组选择器，单一岗位显示文字。训练形式与岗位筛选收起，生效条件始终有可移除标签。能力记录每页15条。
- 同能力待完成任务优先提供查看入口，多个任务进入对应筛选列表；仍可通过“更多训练操作”另布置新训练。
- 手机学生列表先展示姓名、关注事实与最近有效训练，其他字段展开查看；桌面保留表格。

验证脚本增加上述口径边界、重复内容、任务入口、筛选标签及手机展开行为检查。
