# 教师端全局联动整合

2026-10-03。按用户指定顺序完成：统一实体与数据源 → 筛选及返回 → 报告 → 旧页与重复展示。压缩包里的提示词仅作为规格参考，不视为额外用户指令。

## 统一实体和结果口径

- `teacherRoster.js` 保留班级、学生和成员关系种子；`trainingTasks.js` 是任务、参与快照、执行状态和延期事件的数据源；`teacherData.js` 汇总统一训练记录及报告。总览不再生成第二套 `demo-student-*`、`demo-task-*`。
- 学生沿用 `ci-*` ID。既有班级任务和新建任务均使用原任务 ID；执行结果沿用结果 ID，并明确关联训练记录和报告，不按名称或名单序号猜测身份。
- 发布后的任务同步进入教学总览、班级任务明细、学生任务历史及分析。没有报告正文的已完成任务仍保留完成事实，不生成虚构报告。
- 能力计算共用 `currentAbility`：当前连续岗位/模型/版本阶段内，每名学生最近最多3次有效评分等权；切换版本不拼接旧评分。班级均值及分布选样本最多的同版本组。缺失能力不补0，单项结果不补造其他维度或综合分；80仅是标明的演示目标。
- 演示时钟统一为2026-10-03 15:00（上海时区）。原始历史记录保留原时间。报表中的完成、未开始、进行中与逾期明确区分，总览执行条使用互斥人数。
- 待办延期选择使用“任务＋学生”的执行标识，允许同任务选择，拒绝跨任务延期。保存直接修改统一任务截止时间并记录事件；截止时间对任务全体参与学生生效。

## 筛选与返回

`teacherContext.js` 规范班级名称/ID、周期、来源日期与可返回路由。顶部导航和下钻传递同一范围；学生和任务列表支持多班来源范围。自定义日期可传到班级、训练明细和学生能力，修改周期会清除旧日期范围。每日趋势使用实际所选日期。

学生、任务、报告返回优先保留完整来源 URL，恢复页签、筛选、排序和页码。仅允许已知教师端本地路由，外部 URL 不作为返回地址。报告与任务可互相追溯，避免返回一律落到待办中心。

## 完整报告和教师账号

`/teacher/reports/:id` 提供身份、任务来源、状态、评分模型与版本、能力维度、逐题回答及原评价、表现证据、同口径历史和点评记录。未提供的问题、回答、评价或证据显示具体缺失状态；不会根据评分编造内容。支持生成中、失败、不可访问、不存在与读取失败状态。

演示点评按当前教师和报告 ID 保存追加历史，返回后统一更新待点评状态。真实教师报告授权/详情/点评接口未接入，真实模式明确不可访问，不调用学生私有报告接口。

教师头像菜单进入 `/teacher/account` 和 `/teacher/settings`。昵称和密码设置复用已有用户接口，教师不再进入求职档案页。
