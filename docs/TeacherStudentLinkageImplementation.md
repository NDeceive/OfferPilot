# 两端联动实施方案

2026-10-03，按已授权方案实施真实持久化闭环，沿用 Spring Boot/MySQL/Vue 与已有面试和报告服务。

1. 教师创建/编辑/归档班级，生成和重置邀请码；学生通过邀请码申请加入，教师审核/移出。一个班级第一版由一名创建教师管理；学生可以加入多个班级。
2. 真实任务使用已加入成员分配、岗位、教师指定问题、时长、最低有效次数、最大次数、截止时间和逾期规则。发布后内容冻结，延期和手动结束可独立修改。真实接口优先支持现有 AI 面试；编程演示和复杂模板继续明确区分。
3. 学生在“教学任务”开始或继续训练。服务端控制任务题目和规则，将 assignment→attempt→session→report 持久化，重复开始不会创建平行尝试。完整回答指定问题且报告评分就绪才计有效次数。
4. 教师授权查看任务报告和原始问答，发布点评；学生在任务结果和原报告读取点评。站内消息承接发布、审核、延期、提醒和点评，消息可以标记已读。
5. 教师真实统计只读取所带班级任务；自主训练保持本人可见且不抵扣任务。任务会话不可物理删除，移出/归档保留历史证据。真实数据与演示种子完全隔离。

数据表：teaching_class、teaching_member、teaching_task、teaching_assignment、teaching_attempt、teaching_review、teaching_message。复用 sys_user、interview_session、interview_message、interview_report。使用唯一约束、事务和行锁保证分配/开始/结果幂等。

前端：教师班级和任务入口在真实模式接入新接口；学生新增我的班级、教学任务和消息页，桌面和手机均可进入；任务面试复用 Interview，报告复用已有内容和点评组件。原演示页面保留作为独立参考。

状态分轴：任务草稿/待开始/进行中/已截止/手动结束；执行未开始/进行中/待校验/已完成；报告生成中/已生成/失败/无效；点评按发布记录；逾期按服务端提交时间计算，不使用报告生成时间。数据库迁移为新增表，不执行旧 schema.sql 的 DROP 操作。

验收：教师A创建→学生B申请→A审核→发布→B完成指定问题→真实报告→A点评→B阅读，独立账号和浏览器验证；教师C被拒绝访问；延期、失败重试、次数限制、重复请求和记录删除保护均测试。

## 已实现与使用方式

- 教师：班级创建、资料编辑、邀请码重置、归档；成员审核、拒绝、移出；任务草稿创建/编辑/删除、发布、延期、结束、未完成提醒；真实学生名单、班级执行统计、报告原始问答与点评。
- 学生：邀请码申请、成员状态、分配任务与历次结果、开始/继续训练、文字或语音作答、任务报告和教师反馈、失败报告重试、消息已读。任务训练不提供跳题或暂停计时；恢复使用服务器剩余时间。
- 新增7张表。本机已执行增量迁移；其他环境先在仓库根目录执行 `node scripts/apply-teaching-migration.cjs`（读取 DB_HOST / DB_USER / DB_NAME / DB_PASSWORD / MYSQL_BIN），再构建并重启后端、构建前端。
- 真实模式为默认；`?demo=1` 保留此前高保真演示，演示本机保存不会修改真实教学数据。真实模式第一阶段支持教师指定题目的面试任务；编程任务、复杂模板、同模型纵向能力成长对比尚未接入持久化。数据分析当前提供真实班级执行完成率，不把演示能力分值混入。
- 一个班级目前只有创建教师管理，公开注册只产生学生身份；教师账号继续通过已有管理/数据库流程开通，不能在注册请求里自行提权。通知为站内消息，无邮件/短信发送。

本地访问：前端 `http://localhost:5173`，新版服务已运行于8080，使用原有账号登录；数字人服务保持按需连接，本轮未自动启动数字人。独立18080验收服务已停止。真实模式的活动入口统一到站内消息，成长入口统一到训练记录，模板入口统一到创建任务，避免重复的空页面；演示模式保留原设计。报告同时展示基础评分、目标匹配度、原始问答、优势/弱项/建议和教师点评，匹配度使用百分比且可超过100，零分不会被旧分数覆盖。

## 验证记录

- Maven 离线 `package`：12项现有后端测试通过。
- `npm run build`：前端生产构建通过（现有 Monaco 包仍有体积告警，未阻止构建）。
- `node scripts/check-teaching-linkage.cjs`：真实 MySQL/API 验证入班审核、草稿编辑/删除与发布冻结、跨教师隔离、重复开始与回答、指定问题完整性、有效/无效结果、最大次数、消息/点评、截止/延期/结束、移出/重新申请、邀请码重置、记录删除保护。报告失败通过修改本次唯一验收尝试的持久化状态模拟，再验证真实重试工作线程，不额外增加训练次数。
- `node scripts/check-teaching-browser.cjs`：Edge浏览器使用真实API验证1440px/390px页面、任务创建/编辑/发布、点评、学生详情任务报告、学生文字作答及报告返回，并断言零分与匹配度单位正确。截图位于 `output/teaching-*.png`。
- 验收脚本仅允许本地服务，会创建 `qa…` 独立测试账号与教学数据，不修改现有账号角色。测试结果保存在 `output/teaching-linkage-result.json`；临时登录文件为忽略提交的本地文件，验收结束删除。
