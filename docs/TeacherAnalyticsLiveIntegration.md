# 教师数据分析正式接入

入口：`/teacher/analytics`。默认页面读取现有授权教学接口，不使用评审稿示例数据，不增加后端写操作。

## 四个工作区

- 覆盖与节奏：按周展示有效训练次数与参与人数，按训练频次核查学生。次数按尝试去重，跨班学生人数去重，未满周单独标识。
- 班级对比：选择2–4个班级，比较参与率、到期分配执行结构，以及同评价方案下的能力目标差距。
- 能力结构：区分能力差距与证据不足，查看学生、原始评分报告并进入个人支持档案。
- 训练后变化：选择已结束任务，核查同一学生、岗位、维度、完整评价标准下的前后配对；后记录在完成后14天内，未满观察期单列。

## 图表与数据匹配

| 数据 | 图表 | 教师可以回答的问题 |
| --- | --- | --- |
| 每周有效尝试数、去重参与人数 | 双轴柱状折线组合图 | 训练量增加是否同时覆盖更多学生？ |
| 0次、1次、2–4次、5次及以上的互斥学生组 | 环形图 | 当前范围中各投入群体占比是多少？ |
| 班内参与率、到期分配执行状态 | 横向柱状图、堆叠条形图 | 哪个班的参与或执行需要跟进？ |
| 班级成员、参与人数、分配数量和明确分母 | 统计表格 | 图表中的比率对应多少实际人数或分配？ |
| 同完整评价方案的班级维度目标差距 | 矩阵统计表 | 哪些能力需求属于班级共同问题？ |
| 可比学生的目标差距分组 | 柱状图 | 短板主要集中在哪个差距区间？ |
| 学生评分证据互斥主状态 | 环形图 | 应先补齐证据，还是开展能力支持？ |
| 本周期训练次数、截至截止的最近可比评分 | 散点图 | 哪些学生投入较多但评分仍低于目标？ |
| 配对学生的前评分、后评分 | 散点图与同分参考线 | 平均变化背后，各个学生发生了什么变化？ |
| 配对学生降低、同分、升高分组 | 柱状图 | 变化方向如何分布？ |
| 完成候选的配对状态与缺失原因 | 环形图 | 配对结论覆盖多少人，其他人为何未进入？ |

环形图只采用互斥分类，并明确总人数；零值不绘制扇区。散点图不抖动或改动真实坐标，相同坐标合并并显示人数，支持点击或键盘打开对应学生及原报告。能力和配对散点同样遵循至少5人的展示条件；CSV附带全部可比学生或有效配对的真实坐标，筛选明细与图表总体分别注明。

## 统计约束

有效训练要求 READY、valid 为 true 或 1、提交时间有效。零分保留；缺失评分不补零。能力统计采用学生最近一份可比评分，每名学生等权；少于5人不展示聚合均值，5–9人提示小样本。跨维度矩阵通过完整评价方案匹配，不把不同标准混合。

当前成员回看历史训练，不代表历史成员快照。执行采用最新个人截止时间，不代表最初截止；按第 minAttempts 次有效提交推导完成时间，无法推导者单列。报告部分读取失败仍保留有效训练次数，但受影响的能力及配对不判断。前后变化只描述观察结果，不证明教学因果。

## 联动与导出

图表可核查学生、记录、分配及评分。个人支持档案接收班级范围、岗位、日期、能力维度和标准，并可返回来源。原任务支持定位分配。班级链接进入当前班级成员与任务管理页，保留分析来源并提供返回入口。

导出当前工作区 CSV，包含范围、标准、口径、读取时间、报告失败数量、图表汇总及相关明细。保留现有 CSV 编码和公式注入防护。

## 验证

- `scripts/check-live-analytics-model.mjs`：去重、班级隔离、数值有效性、零分、完成时间、观察窗口、部分失败、空范围、无效日期及时区边界。
- `scripts/check-live-analytics-browser.cjs`：隔离接口夹具验证四个工作区、跨维度同标准矩阵、分页、CSV汇总、个人日期范围、班级返回、部分失败与1440/390/360宽度。
- 学生支持模型及浏览器回归通过；前端生产构建通过。

浏览器自动验收使用隔离夹具，正式页面使用真实接口。实际数据库的业务数据完整性仍需在登录后的实际教学范围内验收。
