# 教学总览与数据分析恢复记录

更新：2026-10-03。

## 问题与原设计依据

原演示位于 `TeacherWorkspace.vue` 的 dashboard 分支和 `TeacherAnalytics.vue` 的四个分析 Tab。数据分析压缩包的页面规格及 FINAL_OVERRIDES 要求：A01 以时间趋势为核心、不加 KPI 卡墙和待办；A02 对比结构而非排名；A03 保留非因果说明；A04 区分通用与岗位能力，采用学生等权。

两个真实入口此前均转到 TeachingPortal，再由 TeachingInsights 输出同一套指标、提交趋势、完成分布、班级对比、散点和报告表，仅第四块在待办与能力之间切换。这是页面趋同的直接原因。

## 恢复后的分工

| 页面 | 内容与阅读顺序 | 主要操作 |
| --- | --- | --- |
| 教学总览 | 标题及学期/班级/岗位/周期 → 六项摘要 → 训练情况与班级能力表现 → 进行中任务与关注学生 → 今日待办 | 发布任务、看具体任务、看学生、点评与审核 |
| A01 趋势总览 | 训练覆盖趋势、有效训练量、到期按期完成率、单维度目标达成趋势，2×2 图表 | 按周下钻记录或到期任务 |
| A02 班级对比 | 参与率、人均次数、到期任务执行结构、维度目标差距矩阵、来源结构 | 选择2–4个班级、进入班级 |
| A03 训练与干预 | 来源变化、到期执行结构、同口径前后表现、后续变化分布、相关任务 | 查看任务，保留非因果说明 |
| A04 岗位与能力结构 | 岗位样本、目标差距、指定岗位能力、岗位×维度矩阵 | 选择岗位、查看对应记录 |

新增 TeachingOverview / TeachingAnalytics 两个真实数据组件；保留原演示模式页面。复用既有 TeacherChart、AnalyticsChart、Drawer、CSV/XLSX 编码和成长判定，不引入新图表依赖。恢复分析页下划线 Tab、双列图表与独立标题操作区；手机按阅读顺序转为单列。

## 联动与统计

- 数据来自教师获授权的班级、当前成员、任务分配与原始教学报告，不混用示例数字。
- 总览完成率明确是当前范围所有任务的人次分配完成率；进行中的每项任务独立显示完成分配/有效分配，排除减免。
- 总览训练周期与执行截至当前分开表达，全局待办注明不受训练筛选影响。
- 分析按周计算覆盖率；分母是当前成员、跨班去重，历史成员提交仍作为训练量保留。
- 按个人实际截止时间统计已到期分配，第 minAttempts 次有效提交作为完成时间；手动结束与减免排除，时间缺失单列。
- 每个学生仅取最近一次所选维度评分，再学生等权；岗位、模型、规则、提示版本、目标、权重及完整方案共同界定可比组。最大组少于5人不展示均值，方案变化断线，实际0分保留。
- 前后比较可读取同班级范围的历史教学报告，避免分析开始日期截掉任务前基线；任务后窗口为14天，同口径才配对。
- 分析下钻保留 classIds、taskId、from/to、jobId 及 returnTo；记录打开报告再返回保留来源链。到期趋势下钻任务按到期周筛选。
- 修正总览“活跃情况”入口原先误跳消息中心的问题；动态图表仍在活跃情况中保留。

## 数据边界

原演示的四个 Tab 与交互保留，可通过 `?demo=1` 核对。真实数据尚没有教师获授权的自主训练、学生目标岗位、年级和专业字段，不能完整填充这些统计：来源图保留教学记录与缺失说明，不绘制假自主占比；岗位图明确为最近教学训练岗位，不能解释为求职意向。实际报告的自选模块通过“评价维度”呈现，不映射成不存在的通用能力细项。历史评分版本未知时不追溯重算。
