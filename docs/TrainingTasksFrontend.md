# 教师端训练任务 · 前端交付

## 范围与视觉依据

Operate 模式，面向教师布置训练、追踪学生执行、从结果再次干预。用户提供的 V1 落地包是本模块依据：纯白背景、#2AB783 主色、紧凑任务行、五步向导、三标签工作台与模板表格。模块局部样式覆盖，不修改学生端视觉。

文字规格及 FINAL_OVERRIDES 优先于图：T11-01 只保留整体完成进度，统计数据没有小图标；T11-02 状态筛选与最近动态没有彩色圆点，活动按日期组织。不新增彩色条纹、综合分、排行榜或雷达图。

## 数据与状态

现有后端只提供教师概览，没有训练任务 CRUD、发布、对象校验、模板、题库查询或通知契约。因此本次没有创建假生产接口；真实数据模式展示功能尚未接入的状态，操作不写入后端。

`?demo=1` 开启明确标注的本地演示。草稿、发布任务及模板保存在按账号分区的 localStorage；版本检查阻止其他页面的静默覆盖。接口就绪后需接入服务器存储、授权校验和发布事务，不能将此本地存储直接用于生产。

演示以落地包两份 JSON 为统一基线。原列表示例的逾期数有重叠语义冲突，因此学生基础状态互斥，逾期根据当前截止时间重新计算，不作为第四个状态相加；缺少时间的样例补齐演示时间。canonical_task_results.json 是明确标注的补充明细，仅用于 task_logic_8 的 5个有效结果、3提升/1稳定/1下降。不将班级历史报告冒充当前任务结果；其余任务缺少报告时显示“—”。原班级分析任务 ID 可继续打开详情，默认列表只展示新统一基线。

发布固化 participantSnapshot、contentSnapshot、ruleSnapshot，学生进入执行后不提供核心字段编辑入口。延期追加 deadlineRevisions，重新计算未完成对象当前逾期状态，保留 lateCompleted 历史事实。手动结束不可延期。模板只保存目标、内容和次数/补练规则；不保存班级、学生、执行数据或旧日期。使用模板仍从第1步开始。

## 功能限制

- 提醒仅记录演示活动，不发送消息；没有提供不存在的通知开关。
- 内容调整支持推荐方案与自定义题；从真实题库添加/失效题检查需后端接口。
- 已完成样例缺少有效报告明细时不编造平均值。共性薄弱问题缺少结构化归因时展示说明。
- 学生训练入口对截止、补练、手动结束和当前 attempt 的执行约束，服务器发布事务及 RBAC 复核不属于本次前端修改，仍需后端落地。

## 2026-10-03 用户确认的精简调整

本轮以用户明确确认的顺序覆盖原落地包中对应设计：先修正状态与结果口径，再删除重复内容，最后简化筛选和操作入口。包内提示词仅作为实现资料。

- 执行状态保留全部、已完成、进行中、未开始；当前逾期与历史逾期完成属于独立时间属性，可与执行状态组合。旧 status=overdue/late 链接保持兼容。
- 结果只使用本任务的有效报告；比较要求同目标维度、同评分版本、100分量表，按首次和最近完成时间计算原始分差。移除未经确认的±1分分类和70分关注阈值。暂无结果、单次结果及缺少/不一致口径分别解释；跟进学生明确显示执行或报告问题。平均分只在最新结果口径一致时计算。
- 删除概览重复完成率、发布预览右侧重复摘要、重复退出入口和保存提示；任务配置折叠，保留常用事实。移除暂无数据支持的共性薄弱问题。
- 更多筛选按需展开，已生效高级条件保留可移除标签。训练内容统一查看入口，再进入编辑；批量操作只在选择后显示，学生详情直接跳转，已选名单可展开移除。重复训练规则按勾选逐步显示。
